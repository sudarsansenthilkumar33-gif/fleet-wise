## 📌 About the Project

FleetWise is a web-based fleet and dispatch management application designed to make fleet operations more organized, accessible, and user-friendly. It aims to simplify dispatch workflows and provide a centralized interface for managing transportation activities.

## ✨ Key Highlights

- 🚚 Fleet and transportation management
- 📍 Dispatch coordination and operational visibility
- 🖥️ Modern, user-friendly web interface
- 📊 Organized operational information
- ⚡ Streamlined fleet management workflows
- 🌐 Web-based access through a browser

## 🎯 Project Objective

The main objective of FleetWise is to improve fleet operations by providing a centralized digital platform for managing dispatch-related activities, reducing manual coordination, and supporting more efficient transportation workflows.

## 🛠️ Technology Stack

The application uses a web-based frontend and supporting technologies configured within the project. Refer to the source code and configuration files for the exact frameworks, libraries, and services used.

1. Install [Node.js](https://nodejs.org/).

4. Configure the required environment variables.
5. Start the frontend using the scripts defined in its package.json.
